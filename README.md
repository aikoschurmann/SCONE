# SCONE CEGIS Engine

SCONE is a multithreaded Counterexample-Guided Inductive Synthesis (CEGIS) engine written in Zig. It automatically discovers and formally verifies mathematically equivalent bitwise operations and compiler peephole optimizations.

The engine builds expressions from a set of base variables and constants, randomly evaluating them against a grid of data points. Expressions that produce identical outputs across the grid are grouped into "Equivalence Classes". Collisions (where two expressions share a grid output but aren't formally proven to be identical) are exported to a natively linked Z3 Theorem Prover, which mathematically proves their equivalence or yields counterexamples to feed into the next CEGIS iteration.

## Search Space (The Bases)

SCONE explores expressions incrementally by "Cost" (AST depth).

### Cost 0 (The Bases)
All expressions are built from the following Cost 0 leaf nodes:
- **Variables**: `x`, `y`, `z`
- **Constants**: `0`, `1`, `2`, `3`, `4`, `8`, `16`, `31`, `32`, `0xFFFFFFFF` (-1), `0x80000000` (INT_MIN), `0x7FFFFFFF` (INT_MAX), `0xFFFF`.

### Cost N (Combinations)
Higher costs are generated by applying operations to expressions from previous costs:
- **Binary Operations**: `add`, `sub`, `mul`, `and`, `or`, `xor`, `shl`, `lshr`, `ashr`, `eq`, `ult`, `ule`, `slt`, `sle`.
- **Unary Operations**: `not`, `neg`, `clz`, `ctz`, `popcount`.
- **Ternary Operations**: `select` (conditional evaluation).

## Features

- **SIMD Evaluation**: Uses a contiguous, cache-friendly `ClassVectorArena` and unswitched SIMD evaluation loops, evaluating ~160,000 candidate combinations per second across thousands of evaluation points.
- **Native Z3 Integration**: Z3 is directly bound into the Zig binary, avoiding subprocess overhead. Uses multi-threaded proof queries and batching.
- **Proven Cache**: The `ProvenCache` hashes verified AST structures across iterations, permanently memoizing successful Z3 proofs and eliminating duplicate work.
- **Lock-Free Worker Queues**: Threads dynamically pop algebraic combinations using `std.atomic` queues.
- **Depth-1 Pruning**: Prunes trivially useless algebraic combinations (e.g., `x ^ x`, `x - 0`, `x & 0`) before they hit the queue.

## Build

Requires Zig (`0.13.0`+) and the Z3 headers/libraries.
For macOS (via Homebrew):
```bash
brew install z3 zig
```

Build the SCONE binary:
```bash
zig build -Doptimize=ReleaseFast
```

## CLI Usage

Run the engine:
```bash
./zig-out/bin/scone -c <MAX_COST> [OPTIONS]
```

### Options
* `-c, --cost <NUM>`: Max AST depth (cost) to orchestrate (e.g., `3` or `4`).
* `-t, --threads <NUM>`: Number of worker/Z3 threads. Defaults to your physical CPU core count.
* `--no-select`: Disables ternary `select` operations (shrinks the search space).
* `--no-unary`: Disables unary operations (`not`, `clz`, `ctz`, `popcount`, `neg`).
* `--no-prune`: Disables Depth-1 pruning, generating all possible raw combinations.
* `--ce-limit <NUM>`: Caps the maximum number of unique counterexamples added per iteration. (Default: `5000`).
* `--z3-timeout <MS>`: Hard limit for a single Z3 mathematical proof in milliseconds. (Default: `1000`).

## Default Configuration

If no flags are specified, the engine uses the following defaults:
- **Operations Enabled**: `binop`, `unary`, `select`
- **Max Unique Counterexamples per Iteration**: `5000`
- **Z3 Native Timeout**: `1000 ms`
- **Random Samples per Iteration**: `4096`
- **Pruning**: Enabled
- **Cartesian Edge-case Grid**: Disabled

## Architecture & Codebase

* `src/main.zig`: The orchestrator and core CEGIS loop.
* `src/cli.zig`: Zero-allocation argument parser.
* `src/config.zig`: Runtime state configuration.
* `src/database.zig`: Core memory owner (`ExpressionArena`, `ClassVectorArena`, `EquivalenceClass` mappings).
* `src/eval.zig`: Stateless math module containing the core unswitched SIMD batching operations (`combine_binary_into`, etc.).
* `src/enumerate.zig`: Multithreaded lock-free orchestrator that pushes operations to the worker queues.
* `src/verify.zig`: Native multi-threaded Z3 interface and `ProvenCache` logic.
* `src/telemetry.zig`: Metrics gathering and file I/O operations for data analysis.
